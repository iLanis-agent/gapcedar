# Gapcedar 1.0 TEST
Native Java/Canvas Android 8+ Hanare room-size number-gap puzzle.

Place exactly one number in every outlined room. Its value equals the number of cells in that room. Gold given numbers cannot move. For consecutive numbers in a row or column, with no other number between them, the number of blank cells between must equal their absolute difference. Equal numbers must be adjacent if they see each other. Tap a tile to place or remove its room-size number. Twelve distinct 4x4 room boards have twelve distinct unique solutions; each has at most two given numbers.

Saved room palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java selected-cell sets and all aligned number pairs, rejecting pairs with an intervening selected cell, agree with production directional nearest-number scans and room counters on all 65536 masks per board. Exactly one solution per board; fixed givens, bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current 803-entry registry, 128 partial recovered README records and exact Bendivory cumulative stage found no Hanare or Hanaregumi match. Unlike Ripplegrove/Ripple Effect, which fills every room with a permutation and separates equal numbers by a minimum distance, Hanare places only one room-size number per room and constrains nearest visible number pairs by exact blank gap equal to their difference. This changes both placement state and the validator, not just names or art. Shugaku was rejected as existing Pillowfen; Nawabari as Willowcourt; Context as Thistlefern; Detour as Bendhollow. Known Hanare genre, not a global invention. Partial corpus, not ALL-local. Rules: https://www.janko.at/Raetsel/Hanare/index.htm and https://www.cross-plus-a.com/html/cros7hnre.htm . The former German and Japanese wording makes clear that distance counts intervening blank cells.
